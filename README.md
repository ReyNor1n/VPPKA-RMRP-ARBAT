# Сайт ВППКА — «Коммунисты Арбата» (RMRP, сервер Арбат)

Статический сайт (HTML/CSS/JS). Весь контент — в одном файле `content.json`. Сервер не нужен.

## Файлы
- `index.html`, `style.css`, `app.js` — сайт; `content.json` — весь контент; `img/` — эмблема, баннер, печать.
- `admin.html` — админ-панель владельца.

## Бесплатная публикация (GitHub Pages, рекомендуется)
1. Зарегистрируйтесь на github.com, создайте **публичный** репозиторий, например `vppka-site`.
2. «Add file → Upload files» — перетащите всё содержимое папки (не саму папку), нажмите Commit.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://reynor1n.github.io/VPPKA-RMRP-ARBAT/`.

Альтернатива: Netlify (app.netlify.com → «Deploy manually» → перетащить папку). Тогда правки делайте в локальном режиме админки и заново загружайте папку/файл.

## Админ-панель (только вы)
Опубликовать изменения может только тот, у кого есть доступ к вашему репозиторию GitHub.
1. Создайте токен: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. Repository access: только `vppka-site`; Permissions → Contents: **Read and write**. Никому его не передавайте.
2. Откройте `https://reynor1n.github.io/VPPKA-RMRP-ARBAT/admin.html`, введите `ReyNor1n/VPPKA-RMRP-ARBAT`, ветку `main` и токен → «Войти».
3. Вкладки: общие настройки (название, лозунг, ссылка на анкету, логотип), главная, о партии, программа, устав, **руководство и состав** (имя, должность, группа, фото, описание), новости, правовая база, контакты. Можно добавлять/удалять/двигать элементы и загружать фото.
4. «Предпросмотр» — посмотреть до публикации. «Опубликовать» — сохранить в репозиторий; сайт обновится через 1–2 минуты.
5. «Скачать content.json» — резервная копия. «Локальный режим» — правка без токена с экспортом файла (опубликовать так нельзя — только вручную загрузить файл в репозиторий).

Токен хранится только в вашем браузере; кнопка «Выйти» его удаляет. Если токен утёк — удалите его в GitHub.

## Кнопка «Вступить»
Все кнопки ведут на анкету `#join` на сайте. С v232 подать заявку может только зарегистрированный пользователь (профиль на сайте + привязанный Discord): гостю кнопка показывает ошибку «Чтобы вступить в партию, нужно зарегистрироваться на сайте.» с кнопками «Регистрация» и «Войти», прямой переход на `#join` — то же вместо анкеты.

## Правовая база
Выдержки перенесены дословно с forum.rmrp.ru (Конституция гл. I, УК гл. XVII и XXII, Избирательный кодекс гл. III, Правила выборов) со ссылками на источник. Законы на форуме меняются — периодически сверяйте и обновляйте через админку.

## Локальный просмотр
`python3 -m http.server` в папке → http://localhost:8000 (через двойной клик по файлу content.json не загрузится).

## Деплой
Перед каждым коммитом: `node tools/bump.mjs` — унифицирует ?v=, повышает CACHE в sw.js и пишет version.json (сайт и PWA обновятся у всех сами в течение ~1 мин).
После `git push`: `node tools/publish-version.mjs` — ждёт, пока Pages отдаст новый version.json, и пишет meta/site.version в Firestore: открытые вкладки обновятся за секунды (иначе — опрос раз в 60 с).
